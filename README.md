# IPL 2022 StatVault

IPL 2022 match data analysis using Python (pandas, matplotlib, seaborn).

## Dataset

`IPL.csv` contains 20 columns per match:
- match_id, date, venue, team1, team2, stage
- toss_winner, toss_decision
- first_ings_score, first_ings_wkts, second_ings_score, second_ings_wkts
- match_winner, won_by, margin
- player_of_the_match, top_scorer, highscore, best_bowling, best_bowling_figure

## Notebook

`IPL_data_analysis.ipynb` — exploratory data analysis and visualizations.

## Requirements

- Python 3.x
- pandas, matplotlib, seaborn, jupyter
